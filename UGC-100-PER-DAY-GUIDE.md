# DigProg — Create 100+ UGC videos/day (step-by-step)

Goal: flood distribution with short, on-brand clips that drive waitlist signups — without inventing 100 unique films by hand each day.

## 0) Principles (read once)

1. **Templates > inspiration.** 8–12 master formats, infinite topic fills.
2. **Batch, don’t improvise.** Record in blocks; edit in queues.
3. **Mute-first.** Hook + caption must work with sound off.
4. **One CTA.** Join DigProg waitlist (link in bio / pinned comment).
5. **Truthful claims.** No fake results, fake students, or borrowed footage brands.
6. **Accounts are distribution pipes.** Creative system is central; posting is parallel.

## 1) One-time setup (half day)

### A. Creative kit
- Phone + cheap tripod OR screen recordings of DigProg diagrams
- CapCut / Descript / Premiere Rush
- Caption style: DigProg blue `#2457E6` + orange `#FF8A3D` emphasis
- Hook font large; bottom third free for platform UI

### B. Asset library folder
```
ugc/
  hooks/           # 50 written hooks
  broll/           # desk, typing, whiteboard, phone UI
  endcards/        # waitlist CTA 2s
  voice/           # optional VO takes
  exports/YYYY-MM-DD/
```

### C. Hook bank (write 50 once)
Patterns:
- “Friends love your app. Will they pay?”
- “Interest ≠ paying demand.”
- “Customer → Offer → Delivery — missing which?”
- “$79 guide. Who buys? How delivered?”
- “Stop building. Start asking who pays.”

### D. Master formats (12)
1. Talking-head hook → 1 diagram → CTA  
2. Text-on-screen lesson bite (3 lines)  
3. Before/after: praise vs paid  
4. Quiz card (question → pause → answer)  
5. “Wrong answer” myth bust  
6. Screen recording of offer canvas  
7. Street-style “ask a beginner” (original)  
8. Timer challenge: write customer in 20s  
9. Green-screen diagram walk  
10. Duet/stitch reply template (platform-native)  
11. Carousel-to-video (3 slides animated)  
12. Remotion still → 4s punch-in zoom

## 2) The daily math (how 100 is possible)

You do **not** invent 100 stories.

| Layer | Count | Notes |
|------|------:|------|
| Master formats | 12 | Reused daily |
| Topics from curriculum | 100 | One per lesson idea |
| Hook variants | ×2–3 | Swap first line |
| Aspect ratios | ×2 | 9:16 + optional 1:1 |
| Accounts | ×N | Same export, different caption |

**Practical production target:**
- **25 unique cuts/day** from one batch session  
- Post each cut to **4–5 accounts/platforms** → **100–125 posts/day**

That is the honest “100+/day” system. Pure 100 unique masters/day is possible later with a team; start here.

---

## 3) Daily workflow (90–120 minutes core)

### Minute 0–15 — Pick today’s packet
- Pull 8 lesson IDs from `FULL-COURSE-CURRICULUM.md`
- Assign each to 1–2 formats
- Write/adapt 8 hooks (or pull from bank)

### Minute 15–45 — Record batch
- Film 8 talking-head hooks in one outfit/lighting
- Capture 8 screen/diagram clips (or Remotion stills)
- Record one CTA endcard

### Minute 45–90 — Edit assembly line
For each of 8 topics:
1. Drop hook take  
2. Drop diagram/B-roll  
3. Auto captions → fix names/prices  
4. Orange keyword highlight  
5. Endcard CTA 1.5–2s  
6. Export 9:16 1080×1920

**Output:** 8 masters × (optional 2 hook variants) ≈ 8–16 uniques

### Minute 90–120 — Multiply
- Duplicate project with alternate hook line (fast)  
- Or change first frame text only  
- Aim **20–25 unique files**

### Posting wave (can be VA / later tonight)
- Upload same 25 files across TikTok / Reels / Shorts / communities  
- Unique caption + first comment with waitlist URL  
- Spreadsheet log: account · file · time · link

## 4) Caption + CTA formula

**Caption:**
`[Hook]. DigProg teaches customer → offer → delivery in short lessons. Waitlist = 30% off.`

**Pinned comment:**
`Join waitlist → [URL] · keep your EARLY-___ code`

**On-screen CTA (last 2s):**
`Waitlist · 30% early bird`

---

## 5) Account strategy (as many as you can operate)

1. **1–2 main DigProg brand accounts** (quality, consistency)  
2. **Clip accounts** that only post lesson bites (no fake persona claims)  
3. **Language/market variants** only if you can moderate comments  
4. Do **not** spam identical posts inside one account within minutes — stagger 20–40 min  
5. Track bans/strikes; rotate formats if a platform throttles

Compliance: original footage/graphics; licensed music or mute; no scraped private content.

With 1 editor + 1 poster, **40 uniques × 5 accounts = 200 posts/day** is operational.

---

## 7) Quality bar (reject list)

Reject if:
- Text unreadable at phone size  
- No CTA  
- Fake testimonials / fake revenue  
- Claims DigProg guarantees income  
- Uses someone else’s course footage  
- Hook > 3 seconds of nothing

---

## 8) Weekly improvement loop

1. Export waitlist signups by day (Neon table)  
2. Tag which hooks were live that day  
3. Keep top 20% hooks; kill bottom 20%  
4. Refresh bank every Sunday
